# AirPods BLE notes

에어팟이 주변에 뿌리는 블루투스 신호를 Mac에서 들으면서 알아낸 것을 정리한 노트입니다. 소스 코드는 없고, 신호의 형식과 확인된 사실만 적고자합니다.

애플이 공개한 규격이 아닙니다. 직접 들은 신호를 맞춰 본 결과이고, 펌웨어나 OS가 바뀌면 달라질 수 있습니다. 확인하지 못한 것은 "미확인"이라고 적었습니다.

## 이 노트가 보태는 것

에어팟 신호의 기본 형식은 이미 공개된 자료에 있습니다([furiousMAC/continuity](https://github.com/furiousMAC/continuity), [CAPod](https://github.com/d4rken-org/capod)). 
아래는 그 자료들에서 보지 못한 내용입니다.

- **맥의 CoreBluetooth는 내 에어팟 신호의 암호화된 끝부분을 이미 풀어서 줌.** 열쇠를 꺼내 직접 풀 필요가 없고, 풀렸는지만 보면 내 기기인지 알 수 있다. -> [ownership.md](ownership.md)
- **케이스가 이어버드와 다른 주소로 보내는 신호가 있고, 거기에 뚜껑과 1의 자리까지의 잔량이 들어 있다.** -> [case-frame.md](case-frame.md)

그리고 이미 알려진 것을 더 자세히 본 내용입니다.

- **뚜껑 바이트**: 열림 횟수로 알려진 값 안에 닫힘 비트가 따로 있고, 횟수와 어떻게 같이 움직이는지.
- **뚜껑 정보가 실리는 신호와 안 실리는 신호**: 이어버드가 케이스 밖에 있을 때 어느 신호를 믿어야 하는지.

-> [airpods.md](airpods.md)

## 어떻게 들었나

- 맥에서 CoreBluetooth로 신호를 듣기만 했습니다. 어떤 기기에도 연결하지 않았습니다.
- 규칙은 본인 기기를 직접 여닫고 끼면서 바이트가 어떻게 바뀌는지 보고 맞췄습니다.
- 다른 모델은 그 규칙이 그대로 통하는 것을 본 범위만 "확인"으로 적었습니다.
- 원본 기록은 공개하지 않습니다.

## 틀린 곳, 빈칸

미확인으로 남은 모델을 갖고 있거나 틀린 곳을 찾으면 이슈로 알려 주시면 감사하겠습니다.
